# Rock, Paper, Scissors - Java GUI

A simple Rock, Paper, Scissors game developed using Java Swing.

## Features
- Graphical User Interface (GUI)
- Play against the computer
- Random computer choices
- Score tracking for the player, computer, and ties
- Reset button to restart the scores

## Requirements
- Java Runtime Environment (JRE) or Java Development Kit (JDK)

## How to Run

### Option 1: Run the JAR file
1. Download `RockPaperScissorsGUI.jar`.
2. Open a terminal in the folder where the file is located.
3. Run the following command:

   ```bash
   java -jar RockPaperScissorsGUI.jar
   ```

### Option 2: Run the Java source code
1. Download `RockPaperScissorsGUI.java`.
2. Open a terminal in the folder containing the file.
3. Compile the program:

   ```bash
   javac RockPaperScissorsGUI.java
   ```

4. Run the program:

   ```bash
   java RockPaperScissorsGUI
   ```

## How to Play
1. Click Rock, Paper, or Scissors.
2. The computer will randomly choose an option.
3. The game will display the result and update the scores.
4. Click Reset to reset all scores to zero.
